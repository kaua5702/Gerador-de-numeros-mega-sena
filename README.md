# Projeto MegaSena 🎲

Este projeto em Java simula um sorteio da Mega-Sena.  
O programa pede o nome do usuário, dá as boas-vindas e gera 6 números aleatórios entre 0 e 59.


# Exemplo de uso

Digite seu nome: Kauã.

Olá, Kauã

Números sorteados:
12
45
7
33
59
21

# Tecnologias usadas

- Java
- Scanner (entrada de dados)
- Random (geração de números aleatórios)
- Estrutura de repetição (while)
